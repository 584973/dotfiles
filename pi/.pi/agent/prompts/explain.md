Explain how the given code or concept works. Assume I am an experienced developer but may be unfamiliar with this specific codebase, language feature, or algorithm.

Structure your explanation:
1. **High-level purpose** — what does this do and why does it exist?
2. **Step-by-step walkthrough** — trace the flow with specific references to variables/functions
3. **Key decisions** — any non-obvious trade-offs, patterns, or assumptions
4. **Context** — how it fits into the broader system (callers, dependencies, data flow)

Use analogies only if they genuinely clarify. Avoid restating the code line-by-line without adding insight.
